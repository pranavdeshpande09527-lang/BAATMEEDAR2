## UI direction

Build a compact single-page web app for **BAATMEEDAR**, inspired by a classic Indian newspaper.

- Text only: no logos, images, illustrations, or decorative icons.
- Use `Passion One Designed by Fontstage` for the BAATMEEDAR masthead and `Libre Franklin` for all other text.
- Use warm off-white paper, near-black text, thin black rules, subtle grey dividers, and restrained muted red only for warnings or verdict emphasis.
- Use sharp rectangular edges only: no rounded corners, pills, floating cards, gradients, glass effects, or shadows.
- Use newspaper columns, uppercase section labels, strong hierarchy, and dense but readable typography.
- Include input modes for Direct Statement, Article Link, and YouTube Link.
- Show the five stages as inspectable editorial sections, including source extraction, claims, research evidence, independent verifier results, and final verdicts.
