4. Build API Budget + Cache Layer
Do this before integrating Gemini/Groq/Grok/Tavily deeply.
Rules:
- Cache article text by URL
- Cache YouTube transcript by video ID
- Cache search results by query
- Cache source summaries by URL
- Merge duplicate claims before verification
- Set max claims per input
- Set max searches per claim
- Stop searching once enough evidence exists
Example config:
MAX_CLAIMS_PER_CHECK = 8
MAX_SEARCHES_PER_CLAIM = 2
MAX_SOURCES_PER_CLAIM = 4
MAX_MODEL_CONTEXT_CHARS = 12000
ENABLE_CACHE = true
This protects you from expensive runaway API calls.
